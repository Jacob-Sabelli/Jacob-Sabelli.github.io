# Jacob Sabelli — Portfolio

Static personal site for [Jacob Sabelli](https://www.linkedin.com/in/jacob-sabelli/).

## Run locally

```bash
python -m http.server 8765
```

Open http://localhost:8765

## Structure

- `index.html` — home (intro + project timeline)
- `projects/` — project detail pages
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/images/` — photos, CAD renders, icons
